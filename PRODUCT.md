# Product

<!-- impeccable:product-schema 1 -->

## Platform

adaptive

## Users

Data and business analysts with varied experience. They connect data sources, build data models, and create reports.

## Product Purpose

Datan turns data into information through data connections, query preparation, relationship modeling, and interactive reports.

## Positioning

Datan combines data preparation, data modeling, and report creation in one desktop workspace.

## Operating Context

Users work in the native macOS desktop app. They can create an empty report, open a Datan report or project file, and connect to PostgreSQL. Saved connection profiles are stored locally.

## Capabilities and Constraints

- The app creates new reports and opens supported Datan files.
- The app stores PostgreSQL connection profiles without passwords.
- Power BI `.pbix` import is not available.
- The app uses GPUI for its native interface.

## Brand Commitments

- Product name: Datan.
- The user selected the cobalt Datan symbol for the app identity.
- The user prefers restrained, professional product design, with references to Linear, Apple, Obsidian, and Cursor.

## Evidence on Hand

- Brand assets: `branding/datan-identity/`.
- The product has real report, data, model, and connection workflows in the repository.
- Do not invent report history or connection status.

## Product Principles

- Make the next useful action clear.
- Show saved work and source state only when the app can verify it.
- Keep data, model, and report workflows connected.
- Use clear Spanish labels for user actions.
